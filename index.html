サイト構成の分析

01 / サービス中心の構成

4 つのサービスは独立ページです。海上・航空・陸上輸送と通関は貨物物流ページ内の項目です。

02 / 問い合わせ窓口を集約

03 / ニュースリンクの修正が必要

全 4 言語のニュースが 404 を返します。プロジェクト物流ページには仮の文章も見られました。

確認範囲と見方

2026-11-11 に公開ナビゲーションと直接リンクを確認しました。全言語の 48 URL のうち、44 件は HTTP 200、ニュースの 4 件は HTTP 404 でした。ホーム・貨物物流・お問い合わせページの全言語 32 アンカーを HTML と照合しています。HTTP 200 はアクセス可能であることを示し、フォーム送信は検証していません。

見出しと説明は、公式サイトの構成に基づく多言語の要約です。公式サイトへのリンクは選択言語に連動します。分類は本マップの整理用で、独立したページではありません。/sitemap.xml は確認時に 404 でした。公開ナビゲーションにないページは対象外です。
