# Changelog

## 1.2.0

- Share the enquiry API between the Node server and Cloudflare Workers.
- Add the D1 schema migration and a separate full-site Workers build.
- Present enquiry management as a sortable, paginated table with CRUD dialogs.

## 1.1.0

- Add a Node and SQLite backend for customer enquiries.
- Add administrator login, enquiry search and filters, status updates, and internal notes.
- Add direct submission and a reference number when the homepage is served by Node.

## 1.0.4

- Display the release version in the homepage footer in every language.
- Keep the visible version and runtime language switching synchronized with package.json during release builds.

## 1.0.3

- Bump the release version and redeploy the current website.

## 1.0.2

- Refine the English hero with a clearer logistics headline and balanced responsive layout.
- Add a cargo-aircraft photograph sourced from Northgo's existing website.
- Preserve the other language hero layouts and the services anchor.

## 1.0.1

- Replace the text logo with the official Northgo website vector artwork.
- Use the official teal/blue logo on light backgrounds and teal/white logo in the footer.

## 1.0.0

First versioned release of the Northgo website proposal.

- Four-language website redesign and responsive navigation.
- Seven-office world map, region filtering and office contact cards.
- Service-specific enquiry preparation, preview, download and email drafts.
- Detailed and compact multilingual sitemaps.
- Reproducible static release with version metadata and GitHub Pages workflow.

This remains a website proposal; enquiries are not submitted to a backend.
